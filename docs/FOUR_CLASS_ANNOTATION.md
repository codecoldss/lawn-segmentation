# 第二阶段过曝草标注草案（待老师确认）

当前三类模型及验收标签保持 `0=背景、1=草地、2=泥土草`，没有第四类结果。本规范是新增标签前的草案。

- `3=过曝草`：根据邻域、同序列相邻帧和草地连续性可以确认属于草地，但强光使草叶纹理大面积丢失，区域明显饱和。单凭白色或高亮不得判为过曝草；白墙、天空、道路、石头仍按真实对象标注。
- 普通亮草、阴影草、发红或枯黄草，只要纹理可辨且属于原有草地定义，仍按1；裸土混草按经老师确认的2类定义。原标签中石板和道路出现2类，需要先统一类别语义。
- 无法确认的白亮区域记录为待裁定，不擅自改为0或3；当前训练不支持忽略标签，裁定完成后再纳入训练。
- 两名标注者独立复核至少30张含过曝、阴影、红草、灌木边缘及硬质道路的图片，记录分歧及裁定；冻结标注规则、数据版本和分组划分。

补齐249个空标签并完成复核后，再统一修改数据检查、类别映射、模型输出通道、调色板、评测和导出。固定采集组验证划分及训练预算；报告四类IoU，并同时报告合并1/3为草地后的共同类别指标，使与三类基线的比较可解释。
